# 苍穹战机 · Sky Wing

网页版空战 / 巡航：开局即飞，顶部仪表盘，机场跑道降落，主线与支线任务。

## 快速开始

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080 —— 进入后直接上天。

## 玩法概要

- **开局即飞**：顶部仪表盘显示空速 (km/h)、高度、血量、油量
- **启航海域**：两座小岛 + 一片大陆，各有机场跑道；积分越高解锁更大地图
- **降落**：飞到跑道上方，用 `C` 降到约 120 m 以下，点击「降落」补给（恢复起飞时的血量 / 弹药 / 燃油）；停场后按 `W` 再起飞
- **耗油**：按空速计算，飞得越快越耗油
- **主线**：每日任务；**支线**：每日随机，左侧任务栏可查看 / 领奖
- **基地**：点「基地」可改装机库、买武器、换地图、选作战模式

## 操作

| 按键 | 作用 |
|------|------|
| A / D | 左右转向 |
| W / S | 油门 / 减速 |
| R / C | 爬升 / 下降 |
| 空格 | 机炮 |
| Q / E / G | 短距弹 / 中距弹 / 火箭 |
| 跑道 + 低高度 | 点击「降落」 |
| ESC | 暂停 |

进度保存在浏览器 `localStorage`（`skywing_save_v3`）。
